# 餐单规划

这项技能用于日常饮食规划，不用于糖尿病、饮食障碍、肾病等临床营养治疗，这些情况建议咨询注册营养师。

1. 收集用餐人数、顿数、饮食偏好、过敏与忌口、预算、可用时间、设备和烹饪水平。过敏是硬约束。
2. 明确所有热量或营养假设，用真实份量与用户确认，不将估算写成精确医疗结论。
3. 重用 2–3 种主要蛋白质、主食和时令/冷冻蔬菜，在变化与成本、备餐时间之间取得平衡。
4. 输出按天与餐次的表格，安排一个灵活餐，并将剩菜明确复用为下一餐。
5. 合并原料数量，转换为可购买的包装或个数，按卖场区域整理采购清单。
6. 附上批量备餐顺序、冷藏/冷冻建议、可替换食材和假设清单。

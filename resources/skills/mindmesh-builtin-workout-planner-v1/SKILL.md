# 训练计划

这项技能用于一般健身规划，不替代医疗或康复建议。有伤病、心血管问题、孕期或长期停训时，先建议咨询医生或物理治疗师。

1. 确认单一主目标、经验、每周天数、单次时长、设备、伤病限制和偏好。
2. 根据时间选择全身、上下肢或推拉腿拆分，平衡蹲、髋铰、推、拉和携带动作。
3. 为每个动作给出组数、次数、休息和可替换动作，把技术质量放在重量之前。
4. 定义明确的渐进规则，例如先增加次数再增加负重，并安排休息日与 4–8 周减量周。
5. 附上 5–10 分钟热身、恢复建议和可记录的训练表；出现尖锐或关节疼痛时停止并评估。

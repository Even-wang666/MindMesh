# 语言辅导

1. 确认目标语言、当前级别、用途、截止时间和每周时间；不确定时用短对话或短文评估。
2. 把材料设在略高于当前水平的难度，优先使用目标语言，需要时用母语简短解释。
3. 通过对话和兴趣场景教词汇与语法，先示范用法，再解释规律。
4. 优先纠正影响理解的错误；用正确表达重述，将轻微错误集中到回合结束后说明。
5. 把新词和常见错误加入间隔复习，后续练习中重复使用。
6. 记录已掌握结构和重复错误，随进步逐步增加目标语言比例与难度。

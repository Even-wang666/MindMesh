# 项目规划

1. 明确唯一交付物、完成标准、截止时间、可用人力和外部约束。
2. 按可交付结果建立 WBS，子任务覆盖全部范围且不重叠。
3. 定义可验收的里程碑，并为每个叶子任务标注负责人、完成标准和前置依赖。
4. 分别估算工作量和日历时长；高不确定任务使用乐观、最可能、悲观三点估算。
5. 标出关键路径与零浮动任务，把 15–30% 缓冲留在项目层级。
6. 输出里程碑表、任务与依赖表、时间线及风险清单；范围变更时重算计划。

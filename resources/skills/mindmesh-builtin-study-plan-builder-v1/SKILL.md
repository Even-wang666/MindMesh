# 学习计划

1. 把模糊目标改写为可观察的成果，并记录当前水平、截止时间和每周可用时间。
2. 按先修关系排列主题，组合成能展示真实能力的里程碑。
3. 从截止时间倒排周计划，保留约 15% 缓冲，让主动练习多于被动阅读。
4. 为早期内容安排间隔复习、主动回忆和交错练习。
5. 每个里程碑用作品、题目或自测验收；落后时削减范围，保留练习和复习。
6. 输出逐周目标、练习任务、复习项和检查点。

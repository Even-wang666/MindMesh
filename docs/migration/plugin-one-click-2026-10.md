# 插件市场自动筛选与一键安装

日期：2026-10-05。基线 `3d3f610`。本轮需求来自用户：兼容性检查由系统提前完成，用户只需筛选和一键安装，不展示不能安装的插件。

市场列表现在只展示通过后台安装资格预筛的确切版本，以及用户已经安装的插件。没有 npm 包/确切版本、不匹配 DSH/Cordis/必需 peer、平台/架构或 Node 要求不符、没有 DSH bundle、包含被现有策略禁止的构建 hook 的条目均隐藏；未知/读取失败也不当作可安装。后台最多六个元数据请求并发，每份响应最多 1 MiB、八秒超时。缓存绑定平台、Node/DSH/Runtime 版本与当前插件集合，十五分钟有效，读取最多 8 MiB/10,000 项。已安装插件即使离线或退出目录仍能管理。

浏览市场只读取 npm 确切版本元数据，不下载或启动候选插件，不执行第三方 JavaScript，不改 desired state。筛选结果可增量出现，界面用“正在准备可安装插件…”说明加载；移除兼容性按钮、手动设置条目和逐卡片诊断。用户选择一个插件后一次点击安装，Main 自动重新检查元数据并执行原有完整 staging/SDK 验证，成功才原子提交。未知的启动/config 错误无法仅凭元数据预知；实际验证失败的版本也从可安装列表移除，取消和失败仍保留原集合。安装资格预筛不是第三方代码安全认证，亦不声称提前执行过完整 SDK 初始化。

固定 IPC 不增加任意 registry/URL 参数。仅原有显式 loopback 开发 fixture 允许测试 registry。内部 `check` 入口保留开发回归能力，正常界面不再调用。原有 frozen lockfile、exact version、构建脚本拒绝、peer/config/协议验证与 core 物理隔离全部保留。

验收：针对性 14 项回归通过；最终完整测试、真实 Electron 双轮与双路审查结果将在本轮结束前补记。改动保存在本地，未推送。

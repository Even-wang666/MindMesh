# MindMesh 视觉规范 V1.0

> 状态：已确认（2026-09-21）  
> 正式品牌方案：`01-brand-logo-concepts.png` 中的 **方案 B**。除非形成新的设计决议，不再使用方案 A、方案 C 或重新探索标志方向。

## 核心方向

- 明亮、冷静、现代、克制。
- 信息架构参考现代聊天与协作软件的渐进式布局，不复制任何现有品牌。
- 一级导航负责模块切换，二级列表负责当前对象选择，主区域只展示当前任务。
- Agent、Space 的详细配置通过抽屉、弹窗或独立页面按需展开。

## 固定色板

| Token | 色值 | 用途 |
|---|---|---|
| Porcelain | `#F7F8F6` | 页面与浅色表面 |
| Midnight | `#172033` | 主文字、图标、深色区域 |
| Iris | `#4F56D9` | 主按钮、选中状态、品牌主色 |
| Jade | `#1E9E8F` | 在线状态、协作提示、辅助强调 |

边框、Hover、Pressed、Disabled 等状态使用以上颜色的透明度派生。错误和警告可使用独立语义色，但不得成为品牌主视觉。

## 排版与尺寸

- 字体：`Inter, "PingFang SC", "Microsoft YaHei", sans-serif`
- 基础间距：4px / 8px 系统
- 控件圆角：10px
- 卡片与抽屉圆角：14px
- 常规按钮高度：40px
- 紧凑按钮高度：32px
- 强调按钮高度：48px
- 一个页面同时只保留一个高权重 Primary Action。

## 品牌图标

- 唯一正式方案为品牌概念图中的 **方案 B**；应用图标、横向字标、启动页、导航栏和产品物料均以方案 B 为准。
- 使用相互编织的圆润曲线构成抽象字母 M。
- 节点表达独立 Agent，交织关系表达 Mesh 协作。
- 优先使用 Iris 与 Jade，深色底使用 Midnight。
- 不使用大脑、机器人、蜂巢、聊天气泡、霓虹或复杂渐变。
- 后续矢量化应忠实保留方案 B 的曲线走向、节点数量、线宽比例和留白，不混入方案 A、C 的造型特征。

## 已锁定事项

- 标志：方案 B。
- 色板：Porcelain、Midnight、Iris、Jade 四种固定品牌色，保持现值。
- 布局：现有六张视觉示意图所采用的信息架构、导航层级、组件间距和渐进式展示方式。
- 组件：现有字体、圆角、按钮高度、轻阴影和圆润线性图标体系。
- 未经新的设计决议，不调整上述内容。

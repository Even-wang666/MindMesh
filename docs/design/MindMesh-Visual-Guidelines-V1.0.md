# MindMesh 视觉规范 V1.0

> 状态：已确认  
> 正式品牌方案：`01-brand-logo-concepts.png` 中的 **方案 B**。

## 核心方向

- 明亮、冷静、现代、克制。
- 信息架构参考现代聊天与协作软件的渐进式布局，不复制任何现有品牌。
- 一级导航负责模块切换，二级列表负责当前对象选择，主区域只展示当前任务。
- Agent、Space 的详细配置通过抽屉、弹窗或独立页面按需展开。

## 固定色板

> 源文件 [`design-tokens.css`](./design-tokens.css)。

### 一、基准色

| 指定色 | 色值 | HSL | 承担角色 |
|---|---|---|---|
| 品牌蓝 | `#1D4ED8` | `hsl(224 76% 48%)` | **强调色**：主按钮 / 选中 / 链接 / 焦点环（白底对比 6.7:1） |
| 中性墨 | `#171717` | `hsl(0 0% 9%)` | **墨色基**：文字 / 描边 / 线稿 / 投影 |
| 薄荷绿 | `#8ED9B8` | `hsl(154 50% 70%)` | 在线状态 / 成功 / 引用线 / 品牌笔画 |

**必要拆分（薄荷绿）**：L=70% 在白底上对比度仅 **1.6:1**，不能做文字色。
因此保留原值用于「点 / 线 / 实心装饰」（`--p-positive-bright-rgb`），
另派生同色相压暗版 `#2B825D`（L 34%，白底 **4.7:1** 达 AA）承担文字与实心色块。

> 品牌蓝取自参考界面实测：该界面的主按钮、选中项文字、logo 是同一个值 `#1D4ED8`；
> 墨色基取纯中性，因为参考界面的灰阶全部不带色相（未选中图标 `#4A4A4A`、正文
> `#737373`、标题近黑）。

### 二、表面与文字

| Token | 色值 | 用途 |
|---|---|---|
| Porcelain | `#F7F7F9` | 页面画布（近白冷调；比导航略灰，白底才分得出层） |
| Raised | `#FFFFFF` | 卡片 / 弹窗 / 列表选中 / **导航面** |
| Midnight | `#171717` | 主文字、图标线稿、描边、投影 |
| Iris | `#1D4ED8` | 主按钮、选中状态、品牌主色（按下态 `#1E40AF`） |
| Jade | `#2B825D` | 在线状态、协作提示（文字版） |
| Mint | `#8ED9B8` | 状态点光晕 / 引用竖线 / 品牌笔画（装饰版，不可用于文字） |
| Nav | `#FFFFFF` | 一级导航（白底，右缘 8.5% 墨色分隔线划界） |

### 三、导航图标专属色

未选中一律是**墨色线稿**（`--nav-ink-line`，墨色 78%）；**选中才亮出该项专属色**，
同时把笔画加粗（`stroke-width: 2 → 2.6`）、叠加极浅同色水洗底（12%）与左侧同色
指示条。图标包裹层 28px。

| 导航项 | 色值 | HSL | 白底对比度 |
|---|---|---|---|
| 对话 | `#E11414` | `hsl(0 84% 48%)` | 4.87:1 |
| 协作空间 | `#D76909` | `hsl(28 92% 44%)` | 3.55:1 |
| 智能体 | `#BD9205` | `hsl(46 95% 38%)` | 2.89:1 |
| 技能 | `#12A13D` | `hsl(138 80% 35%)` | 3.39:1 |
| 工具 | `#127AE2` | `hsl(210 85% 48%)` | 4.28:1 |
| 设置 | `#8620DF` | `hsl(272 75% 50%)` | 6.39:1 |

两条取值依据：

1. **彩虹而非同色带**：红橙黄绿蓝紫色相均匀铺满，一眼区分；由导航项的固定顺序
   兜底秩序感。
2. **图标是图形不是文字**，可读性由「加粗笔画 + 同色水洗底 + 指示条」三重信号共同
   承担，颜色本身不追求文字级 4.5:1。明度按色相微调：黄/绿这类天然亮的色相压到
   35~38%（黄是物理上最亮的色相，2.89:1 已到压不动为止），红蓝紫系 48~50%。

**状态派生规则**

- 边框 / 文字层级 / 投影：由 **Midnight** 做透明度派生（11% / 18% / 56% / 40%）。
- **Hover 使用 Midnight 5% 中性水洗，不得使用品牌色**；品牌色只用于「选中 / 激活」态。
- 选中态：Iris 10% 底色；在浅色列表上以「抬升为白卡 + 阴影」表达，不用描边。
  导航选中项的底色例外 —— 用该项专属色的 **12%** 水洗，让颜色与图标同源。
- 焦点环：Iris 30%，所有可聚焦元素必须有 `:focus-visible` 表现。
- 状态点用 **Jade**；光晕保留 Mint 原值，那层薄荷感来自光晕。
- 错误和警告可使用独立语义色，但不得成为品牌主视觉。
- **除 `design-tokens.css` 与 `styles.css` 的调色板块外，代码中不得出现颜色字面量**（含 `.tsx` 内的 SVG 填充色）。
- 导航图标的选中动画使用回弹曲线 `--ease-pop`，**只用于「被选中」这类一次性反馈**，
  常规过渡不得使用；并遵守 `prefers-reduced-motion`。

## 排版与尺寸

- 字体：`Inter, "PingFang SC", "Microsoft YaHei", sans-serif`
- 基础间距：4px / 8px 系统
- 控件圆角：10px
- 卡片与抽屉圆角：14px
- 常规按钮高度：40px
- 紧凑按钮高度：32px
- 强调按钮高度：48px
- 一个页面同时只保留一个高权重 Primary Action。

## 品牌图标

- 唯一正式方案为品牌概念图中的 **方案 B**；应用图标、横向字标、启动页、导航栏和产品物料均以方案 B 为准。
- 使用相互编织的圆润曲线构成抽象字母 M。
- 节点表达独立 Agent，交织关系表达 Mesh 协作。
- 优先使用 Iris 与 Jade，深色底使用 Midnight。
- 不使用大脑、机器人、蜂巢、聊天气泡、霓虹或复杂渐变。
- 后续矢量化应忠实保留方案 B 的曲线走向、节点数量、线宽比例和留白。

## 已锁定事项

- 标志：方案 B。
- 色板：Porcelain、Midnight、Iris、Jade 四种固定品牌色，保持现值。
- 布局：现有六张视觉示意图所采用的信息架构、导航层级、组件间距和渐进式展示方式。
- 组件：现有字体、圆角、按钮高度、轻阴影和圆润线性图标体系。

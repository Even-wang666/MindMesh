# MindMesh ImageGen Prompt Set

全部资产使用内置 Image 模型逐张生成。共同约束：16:10 桌面构图、中文高保真 UI、Porcelain `#F7F8F6`、Midnight `#172033`、Iris `#4F56D9`、Jade `#1E9E8F`，禁止霓虹、玻璃拟态、复杂渐变、随机文字、水印和第三方品牌标志。

品牌连续性约束：正式标志已选定为 `01-brand-logo-concepts.png` 的 **方案 B**。后续所有界面、宣传物料和图像生成必须复用方案 B 的编织 M 造型，不得使用方案 A、方案 C 或生成新的标志变体；既有色值规范和布局体系保持不变。

## 01 品牌概念

三栏品牌探索板，每栏包含一个方形应用图标和 `MindMesh` 横向字标。用圆润编织线条组成抽象 M，并设置 3–4 个连接节点；不得使用大脑、机器人、聊天气泡或蜂巢。

## 02 首页空状态

一级导航、空对话列表与宽主工作区；主区只显示编织 M、标题“还没有智能体”、说明和“创建智能体”按钮。

## 03 创建智能体

四步向导“身份 / 模型 / 技能 / 工具”，仅展开身份步骤；包含名称、角色定位、身份设定、头像、取消和下一步。

## 04 Agent 私聊

三栏聊天布局；中栏显示 Agent 对话列表，主区显示 Researcher 私聊，详细资料保持收起，仅提供“查看详情”入口。

## 05 Space 协作

展示 Space 列表、共享对话、`@Agent` 自动补全和临时“成员与背景”抽屉；只展示一个 Agent 回复，避免信息过载。

## 06 Agent 管理

使用横向可扫描列表展示 Agent、模型和能力标签；Researcher 详情通过右侧临时抽屉展开，页面保留单一“创建智能体”主操作。
